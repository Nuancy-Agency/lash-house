# Lash House

Site institucional da Lash House, estúdio especialista em extensão de cílios (fio a fio, volume, híbrido, lash lifting) em Lisboa, com atendimento a clientes de mais de 30 países.

## Stack

- [Astro](https://astro.build) — geração de site estático
- [Tailwind CSS v4](https://tailwindcss.com) — estilos
- [Alpine.js](https://alpinejs.dev) — interatividade leve (menu, CTA sticky)

## Comandos

Todos os comandos são executados a partir da raiz do projeto, no terminal:

| Comando           | Ação                                            |
| :----------------- | :----------------------------------------------- |
| `npm install`       | Instala as dependências                          |
| `npm run dev`        | Inicia o servidor local em `localhost:4321`      |
| `npm run build`      | Gera o site de produção em `./dist/`             |
| `npm run preview`    | Faz preview local do build de produção           |
